## 1. 打开网站

> **注意**：Docusaurus 生成的是单页应用。**直接双击 `site/index.html` 打不开子页面**，必须先起一个本地 Web 服务。

### macOS

1. 双击 `site/start.command`。
2. 第一次运行如果提示“无法打开，因为它来自身份不明的开发者”，在文件上**右键 → 打开**，再点“打开”。
3. 浏览器会自动打开 <http://localhost:3000>。关掉弹出的终端窗口，服务就停了。

也可以手动运行：

```bash
cd site
python3 -m http.server 3000
```

### Windows

1. 先安装 Python 3（安装时勾选 **Add Python to PATH**）。
2. 双击 `site/start.bat`，浏览器会自动打开 <http://localhost:3000>。

`localhost` 只指本机。想在手机上看，用 `python3 -m http.server 3000 --bind 0.0.0.0`，再在手机浏览器打开电脑的局域网 IP，例如 `http://192.168.1.20:3000`。

### 部署到服务器

`site/` 是纯静态文件，可以直接放到 Nginx、GitHub Pages、对象存储等。网站假设部署在域名**根路径**；部署到子路径要改 `source/docusaurus.config.js` 的 `baseUrl` 后重新构建。

- 文件名前的数字决定侧边栏顺序；网址由文件开头的 `slug:` 决定。
- 图片放在 `source/static/img/`，页面里用 `/img/...` 引用；每张图都要写 `alt` 和图注。
- 提示框用这五种：`:::tip` 技巧、`:::info` 说明或待补充、`:::warning` 可能损坏硬件、`:::danger` 不可逆操作，以及奶龙专属的 **`:::nailong`**（用奶龙的口吻提醒，黄色虚线框，带小奶龙头像）。
- 查不到、没确认的内容统一写成 `:::info 待补充`。

```bash
cd source
python3 imgtools/diagrams_assembly.py   # 改完脚本重新生成对应 SVG
```

## 3. 重新构建

需要 Node.js 20 以上。

```bash
cd source
npm install
npm run build
./preview.sh
```

有失效的内部链接时 `npm run build` 会报错并列出页面。构建好后把 `source/build/` 的内容复制到 `site/`（保留 `start.command` 和 `start.bat`）。
