## 1. 简介

ottodiy.tech 的下载页可以直接在浏览器里烧录官方 Otto 固件，不用装任何软件。适合第一次上手、或者想把机器人恢复成官方固件的时候用。

:::info
这个方法只能烧**官方固件**（唤醒词是「你好小智」）。奶龙定制固件需要 [自己编译](/docs/flash/build)。
:::

## 2. 准备

- 电脑上装有 **Chrome 或 Edge**（需要浏览器支持 Web Serial，Safari 和 Firefox 不行）。
- 机器人装好电池，用数据线连上电脑。

## 3. 烧录

1. 用 Chrome 打开 [ottodiy.tech 下载页](https://ottodiy.tech/docs/downloads/)。
2. 打开机器人的电源开关。
3. 在页面上选择最新版本的固件（写这篇时是 **v2.5.3**），点「烧录」。
4. 浏览器弹出串口选择框，选机器人对应的串口（见 [串口名称](/docs/flash#4-串口名称)），点「连接」。
5. 等进度条走完。
6. 关掉再打开电源开关重启。

**会看到什么**：重启后屏幕亮起，显示表情。第一次开机还没有配网，机器人会进入配网模式，接下来去 [配网](/docs/debug/wifi)。

## 4. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 弹窗里没有串口 | 数据线只能充电，或浏览器不支持 | 换数据线；换 Chrome / Edge |
| 连接后一直卡住 | 没进入下载模式 | 按 [进入下载模式](/docs/flash#3-进入下载模式) 的步骤操作后重试 |
| 页面提示需要 HTTPS | 打开的不是官网地址 | 用 `https://` 打开官网 |
