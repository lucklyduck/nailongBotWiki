## 1. 奶龙固件

| 版本 | 内容 |
|---|---|
| 2.0.16 | MQTT 重连也走显式 mDNS 解析 `master.local`，换路由器或换电脑不用改固件 |
| 2.0.15 | Otto Master 可以远程进入 / 退出循环对话；先回 ACK 再切换音频通道 |
| 2.0.14 | 动作贴图跟随实际动作任务开始 / 结束；状态查询返回当前贴图、音效、音量 |
| 2.0.13 | 音量迁移到 100（只迁移一次，之后保留用户设置） |
| 2.0.12 | 圆屏表情换成看山贴图（21 个表情 + 动作贴图）；音量 90；动作任务优先级低于音频 |
| 2.0.11 | 按键会话开关：待机按一下进入循环对话，对话中按一下退出 |
| 2.0.8 | 诊断用 `voice_wake`（需要设备 token） |
| 2.0.7 | 支持 WebSocket Profile 和 `preferred_transport` 切换 |
| — | 「你好奶龙」自定义唤醒词、`self.otto.laugh` 奶龙大笑、四舵机无手臂配置 |
