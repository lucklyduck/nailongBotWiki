## 1. 简介

这一页按 NaiFirmware 说明唤醒、笑声、音量与按键。先确认烧入的是配套应用和资源，见 [编译奶龙固件](/docs/flash/build)。

## 2. 开始对话与打断

| 操作 | 当前行为 |
|---|---|
| 待机说“你好奶龙” | 本地唤醒后连接后台 |
| 待机按 BOOT | 开始对话 |
| 最新候选：对话中按 BOOT | 取消话语和动作，继续监听；断线时尝试合法重连 |
| 最新候选：本地识别“停下” | 只停动作，保留当前话语 / 笑声 |
| 云端调用 `self.otto.stop` | 停止动作并归位 |

最新候选的停止延迟、误停率和 BOOT 后继续对话仍待实机验证，见 [功能状态](/docs/intro/status)。语音停止受识别条件影响，不能当作机械急停；新动作先架空测试，异常时关闭电源。

## 3. 能说什么

| 想做什么 | 例子 / 对应工具 |
|---|---|
| 聊天 | “你是谁？”“讲个笑话” |
| 行走、转身、摇摆 | “向前走三步”；`self.otto.action` |
| 本地大笑 | “笑一个”；`self.otto.laugh`，约 5 秒 |
| 边笑边走 | `self.otto.laugh_walk`，组合效果待完整实测 |
| 校准 | `self.otto.set_trim` / `self.otto.get_trims` |
| 音量、电量 | “音量调小一点”“还有多少电？” |

模型需要按 [人设规则](/docs/xiaozhi/role) 调用工具。“听不懂就笑”由云端决定；断网或没有识别结果时不能保证触发。

## 4. 音量和笑声

音量初始值为 **70**，之后读取设备保存值，没有首次启动自动设为 100 的迁移逻辑。可通过语音调整，重启后检查是否保存。

大笑来自本地 `nl_laugh.ogg`，约 5 秒。工具等待播放完成或中断后再返回，不能把“已经调用”当作“已经完整播完”。

## 5. 唤醒不灵怎么办

当前使用中文 MultiNet7，拼音 `ni hao nai long`，阈值 **10%**；阈值越低越敏感，也可能增加误唤醒。

| 现象 | 解决 |
|---|---|
| 偶尔叫不醒 | 靠近一点，降低环境噪声；用 BOOT 对照 |
| 完全叫不醒 | 核对奶龙变体和资源分区，不能只刷应用 |
| 经常误唤醒 | 调高构建脚本中的阈值，重新构建并更新资源 |
| 唤醒了不回答 | 检查网络和绑定，查看串口日志 |
| 声音小或破音 | 检查音量、喇叭接线和电池 |
| 笑声后才走 | 检查模型是否串行调用了两个工具；组合应调用 `laugh_walk` |

具体配置见 [修改唤醒词](/docs/dev/wake-word)。不同环境下的识别率与误唤醒率仍待补充。
