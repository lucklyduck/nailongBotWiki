## 1. 简介

第一次做奶龙的话，按下面 6 个任务走，一个周末就能从一堆零件走到一只会说话、会走路的奶龙。每个任务都写了要读哪几页、大概多久、**做到什么程度算完成**。

| 任务 | 难度 | 用时 | 要读的页面 | 完成标志 |
|---|---|---|---|---|
| Task 0 学前须知 | ★ | 10 分钟 | 本页第 2 节、[产品介绍](/docs/intro) | 知道自己走「套件」还是「自己焊」路线 |
| Task 1 把奶龙装起来 | ★★ | 1～3 小时 | [组装](/docs/assembly) 全章 | 四个舵机都能动，站姿基本正 |
| Task 2 让它亮起来 | ★ / ★★ | 10～40 分钟 | [烧录](/docs/flash) | 屏幕亮起，显示表情 |
| Task 3 让它站直、会说话 | ★ | 30 分钟 | [配网](/docs/debug/wifi)、[绑定设备](/docs/xiaozhi/bind)、[舵机校准](/docs/debug/trim) | 说「你好奶龙，向前走三步」，它走直线 |
| Task 4 给它一个灵魂 | ★ | 20 分钟 | [配置奶龙人设](/docs/xiaozhi/role) | 说一句它听不懂的话，它哈哈大笑 |
| Task 5 教它新本领 | ★★～★★★ | 1 小时起 | [二次开发](/docs/dev) 任选一节 | 奶龙学会一个原来没有的动作、表情或声音 |
| 加分 晒出你的奶龙 | ★ | 30 分钟 | [晒出你的奶龙](/docs/download/share) | 在知乎发一篇帖子 |

一次做完一个 Task 就好，别一口气熬夜。装到一半卡住了，先去对应页面底下的「常见问题」看看，大部分坑前面的人都踩过啦。

## 2. Task 0 学前须知

### 2.1 需要什么基础

| 路线 | 需要会的 |
|---|---|
| 套件 + 官方固件 | 会用螺丝刀、会连 Wi-Fi，不需要编程 |
| 套件 + 奶龙固件 | 会在终端里复制粘贴命令 |
| 自己焊板 | 焊过贴片元件（0603 阻容、QFN 芯片） |
| 二次开发 | 能读懂一点 C++，会用 git |

### 2.2 选一条路线

| 你的情况 | 推荐 |
|---|---|
| 第一次做硬件，想尽快看到效果 | 买官方套件（固件已预烧）+ 按 [当前模型清单](/docs/assembly/print) 打印套件中缺少的结构件，跳过焊接和烧录 |
| 想要「你好奶龙」和看山表情 | 套件 + [编译奶龙固件](/docs/flash/build) |
| 想完整体验从 PCB 到成品 | 立创打板 + 自己焊 + 自己烧 + [打印完整结构件](/docs/assembly/print) |

### 2.3 安全须知

:::warning
- **锂电池**：不要短路、不要刺穿、不要在无人看管时长时间充电。电池鼓包立刻停用。
- **舵机堵转**：听到持续的嗡嗡声、摸到舵机发烫，马上关机。堵转几分钟就可能烧坏舵机。
- **烙铁和热风枪**：用完放回支架，注意别烫到线材和 3D 打印件。
:::

### 2.4 怎么读这份 wiki

- 每页都按「1. 简介 → 操作步骤 → 常见问题」组织，卡住了先看页面底部的常见问题。
- 黄色虚线框是「奶龙说」，是奶龙给你的提醒；橙色「注意」框是可能损坏硬件的地方，一定要看。
- 标着「待补充」的地方是还没确认的信息，按页面上的说明处理，或者跳过。
