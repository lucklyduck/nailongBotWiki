部件与引脚

1. 外观​

需要打印外壳、底座、左右卡销、腿和脚时，请使用 当前八件模型清单，每个 STL 各 1 件。

部件位置说明
圆屏胸口，被双手抱着显示表情、状态栏、对话字幕
腿（左、右）身体下方由「腿舵机」带动，左右转动
脚（左、右）腿的下方由「脚舵机」带动，抬起脚掌内外侧
电源开关身体下方左侧拨动开关
功能键（BOOT）身体下方右侧开机后按一下：进入 / 退出对话（打断）；开机时按住：进入下载模式
Type-C 口身体下方充电、烧录、看日志
喇叭、麦克风身体内
待补充

奶龙外壳底部开关、功能键、Type-C 口的实拍照片。

2. 引脚分配​

下面的引脚是奶龙固件 main/boards/otto-robot/config.h 里的定义，官方 Otto 固件相同。

2.1 舵机​

舵机GPIO代码里的名字
左腿17LEFT_LEG_PIN
左脚18LEFT_FOOT_PIN
右腿39RIGHT_LEG_PIN
右脚38RIGHT_FOOT_PIN
左手 / 右手-1不使用，固件不会注册手部动作

主板上有三组 2×3 舵机排针（HDR1、HDR3、HDR4），每组接两个舵机。每个舵机的三根线从信号到地依次是 信号 / 电源（电池直供）/ GND，所以插的时候棕色线（GND）朝外。

排针接哪两个舵机
HDR1左腿（GPIO17）、左脚（GPIO18）
HDR3右腿（GPIO39）、右脚（GPIO38）
HDR4手臂（GPIO8、GPIO12），奶龙不用，空着
注意

排针的线序是从原理图图片上读出来的，和固件引脚定义一致，但还没有对着奶龙主板实物逐个核对。插错方向一般不会立刻损坏，但舵机不会动；插好后先开机确认四个舵机都能归中。

2.2 音频​

信号GPIO
麦克风 WS / SCK / DIN4 / 5 / 6
功放 DOUT / BCLK / LRCK7 / 15 / 16

麦克风采样率 16 kHz，播放采样率 24 kHz，两路 I2S 分开（simplex）。

2.3 屏幕​

信号GPIO
MOSI / CLK10 / 9
DC / RST / CS46 / 11 / 12
背光3

ST7789，240×240，SPI mode 3，需要颜色反转（DISPLAY_INVERT_COLOR true）。

2.4 电源和按键​

信号GPIO
BOOT 键0
充电检测21
电池电压ADC2 通道 3
待补充

立创原理图上标的是 CHG_DET = IO47、BAT_DET = IO21，和固件 config.h 不一致。本页以实际在跑的固件为准，原理图版本差异待确认。
