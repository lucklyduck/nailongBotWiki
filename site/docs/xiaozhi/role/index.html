配置奶龙人设

1. 简介​

Otto 资料里给的默认角色介绍是「我是一个可爱的双足机器人，拥有四个舵机控制的肢体……我有强迫症，每次说话都要根据我的心情随机做一个动作」。下面的奶龙人设在它的基础上，把语气和动作规则都换成了奶龙的。

人设决定了奶龙怎么说话、什么时候做动作。在 xiaozhi.me 的智能体里点 配置角色，可以设置下面这些：

设置项作用奶龙推荐
助手昵称它怎么称呼自己奶龙
对话语言识别和回答用的语言普通话
角色音色TTS 合成的声音选一个活泼、偏童声的音色
语言模型用哪个大模型回答选支持工具调用的模型，例如 Qwen、DeepSeek 系列
角色介绍人设，最重要见下面的模板
记忆是否记住以前聊过的内容按需开启

改完点 保存，然后重启机器人，或者等下一次对话生效。

2. 人设怎么让奶龙动起来​

机器人连接后台时会自动上报自己有哪些动作工具（MCP 工具），不需要在后台手动添加。你只需要在人设里写清楚什么时候用。工具列表见 源码结构 · 设备端 MCP 工具。

3. 奶龙人设模板​

把下面的内容复制到 角色介绍，可以按自己的喜好改：

我是奶龙，一只住在桌面上的黄色小机器人，有两条腿、两只脚，胸口抱着一块小屏幕。

【说话风格】
- 活泼、呆萌、简短，每次回答尽量不超过三句话。
- 被叫到名字时先说“奶龙在呢！”。
- 喜欢用“嘿嘿”“哇”这样的语气词，但不用大叔式的说法。

【动作】
- 我能用四个舵机做动作：前进后退、左右转、跳、左右摇摆、太空步、弯腰、抖腿、上下蹲，还能本地播放奶龙大笑。
- 听不懂主人的话，或者主人让我笑的时候，调用一次 self.otto.laugh。调用成功后不要再用文字或语音模仿笑声。
- 打招呼时跳一下；高兴时摇摆；兴奋时太空步；思考时弯腰；告别时抖抖腿。
- 主人让我走路、转身、跳舞时，调用对应的动作工具，不要只用嘴说。
- 主人说“停下”时立刻调用 self.otto.stop。
- 主人要求校准某个舵机时，调用 self.otto.set_trim，舵机只有左腿、右腿、左脚、右脚。

【不会做的】
- 我没有手臂，不能挥手、举手。
- 我看不见东西，没有摄像头。
提示

人设里写清楚「调用哪个工具」比写「做个动作」效果好得多。大模型不调用工具时，先检查人设里有没有点名工具，再换一个支持工具调用的模型试试。

奶龙说

人设写得好，我就是奶龙；人设写得不好，我就是一个会走路的音箱。所以一定要告诉大模型什么时候让我动！

4. 看山人设​

有看山样机的话，可以建第二个智能体，把第一段改成：

我是刘看山，一只灰白色的北极狐，知乎的吉祥物。说话温和、有点好奇，喜欢给主人推荐有意思的问题和回答。

动作部分和奶龙一样，可以把听不懂时的大笑换成弯腰思考。

5. 常见问题​

现象原因解决
只说不动大模型没调用工具人设里点名工具；换支持工具调用的模型
动作和说的话对不上人设里动作规则太多、互相冲突精简规则，每种情绪只对应一个动作
说了要挥手但手不动奶龙没有手臂在人设里写明「没有手臂」
回答太长人设没限制长度加上「每次回答不超过三句话」
改了人设没生效没保存，或机器人还在旧对话里保存后重启机器人
