唤醒与声音

1. 简介​

这一页讲怎么和奶龙开始对话、怎么调音量，以及唤醒不灵时怎么排查。

2. 开始和结束对话​

方式奶龙固件官方固件
说唤醒词「你好奶龙」「你好小智」
按功能键（身体下方右侧）待机时按一下进入对话；连接中、听你说话或正在回答时再按一下，退出到待机按一下开始对话 / 打断
自动结束一段时间没人说话后回到待机同左

对话中机器人执行动作时，你仍然可以说话，比如说「停下」让它立刻停止。

3. 能说什么​

类别例子
聊天「你是谁？」「讲个笑话」
走路「向前走」「向前走五步，快一点」「后退」「左转」「右转」
动作「跳一下」「摇摆」「跳个舞」「太空步」「弯弯腰」「抖抖腿」「上下蹲」
奶龙专属「笑一个」→ 播放约 2 秒奶龙大笑
停止「停下」「停止」
设备「音量调大一点」「还有多少电？」
校准「把左脚校准到 10 度」

动作的完整参数见 二次开发 · 源码结构。

奶龙说

叫我「你好奶龙」，四个字说清楚。叫「奶龙奶龙」我是不理的哦，嘿嘿。

4. 音量​

奶龙固件第一次启动时会把音量设为 100（最大）。之后你用语音调过的音量会被保存，重启不会被覆盖。

5. 唤醒不灵怎么办​

奶龙固件的唤醒词是用乐鑫 MultiNet 中文命令词模型做的自定义唤醒词，拼音 ni hao nai long，初始阈值 20%。

现象原因解决
说了没反应环境太吵 / 离得太远靠近一点、说清楚一点；或者按 BOOT 键代替
完全唤醒不了只烧了主程序，没烧唤醒词模型用完整的 idf.py flash 重烧，见 编译奶龙固件
经常误唤醒阈值太低在 menuconfig 里调高阈值，见 修改唤醒词
唤醒了但不说话没联网 / 没绑定看屏幕状态栏，或 看串口日志
声音小、破音喇叭没接好 / 电量低检查喇叭插头，充电
待补充

「你好奶龙」在不同环境下的实测识别率、推荐阈值。
