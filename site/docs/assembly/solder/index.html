焊接主板

1. 简介​

买官方套件或者成品板的话，跳过这一页。

自己做板：在 ottoRobotV1.1 的 PCB 直接下单，作者说明「什么都不用改」。器件大多可以按 BOM 在立创一键下单，功能键（TS35CA）可能要单独买。

信息

立创工程里还有一个「模块直插新手友好 V1.1」版本，麦克风和功放用模块直插，焊接难度更低，适合第一次焊贴片的人。

立创 EDA 有个「焊接辅助工具」：左边是 BOM，点哪个器件右边 3D 图就高亮它在板上的位置，焊的时候很省事。

2. 难焊的几个器件​

参考 ottodiy.tech 的 焊接指南：

器件要点
麦克风 ICS-43434第 3 脚 GND 那一圈一定要焊好，否则会发热、不稳定甚至烧坏。别长时间用风枪吹：先给焊盘上锡，吹化后迅速放上麦克风
功放 MAX98357A注意方向，芯片上的 + 对准右上角白点
ESP32-S3 模组底部散热焊盘最好也焊上：涂锡膏后放加热台，或用热风枪
充电指示 LED左边是负极（绿色竖线朝左，或底部三角尖朝左）。不插电池时微亮是正常的

2.1 实拍参考​

以上实拍图来源：ottodiy.tech 焊接指南。

通用技巧：烙铁 320～350 °C，每个焊点加热不超过 3～5 秒，烙铁头保持干净，同时加热焊盘和引脚。

3. 焊完检查​

  1. 目视检查有没有连锡、虚焊。
  2. 万用表量 3.3 V 和 GND 之间没有短路。
  3. 用酒精清掉助焊剂残留。
  4. 插 USB，电脑能识别出串口，就可以去 舵机归中 烧录了。
危险

3.3 V 和 GND 短路时不要接电池。锂电池短路电流很大，可能烧坏板子甚至起火。
