装腿和脚

1. 装腿（对应视频 P3）​

关于下面的步骤图

标「渲染图」的来自 ottodiy.tech 的 Otto 原版组装教程，颜色和奶龙样机不一样（原版是灰色身体、粉色脚），但腿脚和底座是同一套零件，装法完全相同。

  1. 用舵机包里的两颗大螺丝，把两个腿舵机固定到机身底座上。
  2. 修剪十字摇臂：用斜口钳把较长的两端各剪掉一半左右。
  3. 把十字摇臂装进腿部零件。
  4. 把腿装到舵机输出轴上，注意方向：
  • 腿上的圆柱凸起朝屏幕一侧
  • 腿垂直朝前，不要内八或外八。差一点点没关系，后面可以 软件校准
  1. 拧上摇臂中间的固定螺丝。

以上渲染图来源：ottodiy.tech 组装教程 第 3 步。

2. 装脚（对应视频 P4）​

  1. 用脚部专用形状的摇臂，垂直朝上装到脚上，拧紧螺丝。
  2. 把脚舵机装进脚里，舵机线从腿里穿进身体。
  3. 把脚装到腿上，拧上舵机固定螺丝。

以上渲染图来源：ottodiy.tech 组装教程 第 4 步。

3. 检查​

  • 两条腿竖直、互相平行
  • 两只脚平放在桌面上
  • 舵机线都穿进了身体，没有被夹住
奶龙说

差几度没关系，后面我可以自己「校准」。但要是差了半个齿以上，最好拆下摇臂重新对一次，软件只能救 ±50°。
